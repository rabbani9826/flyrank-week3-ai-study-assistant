# Claude Code Instructions

## Project Overview

This is a capstone project developed using AI-assisted development practices.

## Technology Stack

- HTML
- CSS
- JavaScript
- Node.js
- Git
- GitHub

## Development Conventions

- Keep the code simple, readable, and maintainable.
- Use meaningful variable and function names.
- Follow consistent formatting.
- Avoid unnecessary dependencies.
- Do not commit secrets, API keys, or `.env` files.
- Test changes before committing them.

## Git Conventions

Use Conventional Commits.

Examples:

- `feat: add new feature`
- `fix: resolve bug`
- `docs: update documentation`
- `chore: update configuration`

## AI Assistance

Claude Code should explain significant changes before applying them when practical.

When modifying existing code:

1. Understand the current implementation.
2. Make the smallest appropriate change.
3. Check for errors.
4. Keep the existing project conventions.
